# AgentEmpire — VHS showcase

Open `index.html` in a browser. No build, framework or credentials are needed. The page opens on this project and browses public S/Agency repositories. A private repository adds only its own record.

The supplied Curved VHS Archive theme includes the 3D shelf, four original sprite sheets, embedded fonts, masked captions, timeline, drag/wheel/keyboard navigation, searchable collection and ink-reveal detail sheet. Artwork is decorative; names and metadata are from GitHub. The collection is a snapshot dated 5 November 2026. Website buttons use repository-listed URLs and do not assert service availability.

This standalone showcase is additive. Existing application routes, backends and deployment settings are unchanged. Public archive: https://s-os-agency.github.io/S-OS/
